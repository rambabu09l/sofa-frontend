# TASTES.md

Distilled for Sofa from [Linear](https://linear.app/), [Motion](https://motion.dev/), and [tastes.md](https://tastes.md/).

## REJECT
- Never use purple-to-indigo gradients or glow-as-decoration.
- Never use opacity-on-white to fake gray — use solid `#8a8f98` / `#5e636e`.
- Never exceed `200ms` for UI transitions; never use bounce easing for chrome.
- Never place floating badges, promo chips, or stat strips on the hero.
- Never default to Inter, Roboto, Arial, or system UI stacks for display type.
- Never resolve tension into a lukewarm middle — hold precision and warmth together.

## REQUIRE
- Use restraint first: when in doubt, subtract.
- Maintain negative space ≥ `40%` in the first viewport.
- Use brand `Sofa` as the hero-level signal; one headline, one support line, one CTA group.
- Pair motion with meaning: `150–200ms`, `cubic-bezier(0.2, 0.8, 0.2, 1)`, springs only for gesture.
- Ensure surfaces feel material — soft charcoal depth, hairline borders `#1f2128`, no card clutter in hero.
- Orient toward: Linear (product craft, velocity), Motion (expressive motion, small APIs), Zumthor (silence, material).

## WHEN AMBIGUOUS
- Prefer tension over resolution; surprise through interpretation, not ornament.
- Orient toward: Linear (product craft), Motion (temporal feel), Teenage Engineering (playful precision).
