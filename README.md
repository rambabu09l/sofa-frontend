# Sofa

Product rhythm for teams and agents — React + TypeScript + Tailwind CSS + shadcn/ui + Motion.

Aesthetic judgment lives in [`TASTES.md`](./TASTES.md), shaped by:

- [tastes.md](https://tastes.md/) — judgment layer
- [Linear](https://linear.app/) — product craft
- [Motion](https://motion.dev/) — expressive animation

## Setup

```bash
cd ~/Desktop/projects/sofa
npm install
npm run dev
```

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- shadcn/ui primitives (`Button`, `Separator`)
- Motion (`motion/react`)
